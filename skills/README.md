# 项目 Skill

这些 Skill 来自本项目实际角色工作规则，已移除真实聊天 ID 和本机绝对路径。它们是项目内版本，不会自动更改使用者全局 Skill。

- bankagent-control：总控、企业研究、量化推荐、审核及知识发布规则。
- bankagent-market-researcher：公开市场资料、时点和事实/分析管理。

`<LOCAL_CHAT_ID>` 和 `<PROJECT_ROOT>` 是待部署者替换的占位符。Skill 中的任务账本、人员注册、cases/data 等路径指向部署者自己的运行工作区；公开包不附这些真实记录。规则描述目标流程，不表示仅复制 Skill 就获得身份隔离、联网工具或自动调度能力。角色权限必须在实际宿主和程序中绑定。

配置方法：按所用代理宿主的官方 Skill 加载方式启用所需目录，或在自己的 AGENTS.md 中显式引用；补齐本地人员、知识域和任务目录。不要把示例标识用于真实鉴权。

公开范围仅限业务 Skill；代码研究员 Skill、开发约定及内部研发过程不包含在本仓库。
