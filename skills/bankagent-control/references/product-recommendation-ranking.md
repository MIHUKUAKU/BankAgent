# 产品推荐：定性五项、定量前三

每企每月从当时适用的产品池中定性筛出最可能的5项。依据企业经营、资金与风险需求、既有安排、采用意愿和银行业务价值，逐项写具体场景与入选理由。第一步顺序不是最终推荐名次，不默认任何产品第一，不用资料易得、先核实或假设少作为推荐优势。

对5项全部采用同口径量化，再从银行风险调整后净收益、资金资本效率、可服务规模及落地可能性选前三。比较企业净收益与风险、银行资金资本投入、收益与压力损失，保留两项落选原因。方法见[量化规则](bank-first-quantitative-recommendations.md)。不得先凭定性锁定3项再补数字，也不能只算易取数的产品。

现金管理要考虑已有司库/财务公司后的增量，不凭“可能存在接口缺口”首推。融资与自有资金、既有额度比较；套保考虑自然对冲及存续合约。各候选使用同一证据标准，不因缺客户合同就机械全部否定，也不因银行高收入制造企业需求。

未知参数用有依据估计、区间、单位效率或盈亏阈值继续判断。单位规模与实际项目规模分开；排序随参数变化时给条件顺位与翻转点，不编权重、收益或采用概率。有依据排除的产品保留排除理由。缺失参数下仍必须给出明确推荐顺位：用有依据的估计，或明确说明的基准情景完成量化比较，给出当前建议的第一、第二、第三及剩余候选位置，不得留空或只给无顺序集合。估计不足以支持唯一客观排序时，作出可解释的决策取舍，说明关键假设、敏感性与换位条件；不得冒称这是实测收益排名，不用不确定性代替推荐。

产品推荐任务完成必须逐月交付由五项量化比较产生的明确推荐顺位、前三及其余项落选依据，并可从当期真实数据或有依据估计复算。缺完整项目参数时可给明确基准情景下的量化条件顺位及数值换位阈值；只有公式、阈值清单、比较器测试、定性询价顺序或空排名均属于未完成。不得以这些中间产物的有限范围PASS代替推荐完成。未给出量化推荐顺位就继续估计、替代计算和修订，不停在等待参数，也不得硬编码名次、编造参数或用合成样例冒充历史结论。

正文明确展示第一、第二、第三及理由，五项测算和其余落选依据留配套文件或附录。每个名次按[需求到收益证据链](demand-scale-bank-value.md)追溯至企业需求与可争取业务量。
