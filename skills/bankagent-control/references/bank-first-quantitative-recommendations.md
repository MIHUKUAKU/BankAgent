# 银行优先的量化方法

先定性筛五项，再量化取前三，执行[产品筛选](product-recommendation-ranking.md)。优先比较银行风险调整后净收益金额、资金资本效率、业务规模及落地可能；企业收益风险与采用意愿决定业务是否成立。不能只比较百分比、利率或低资金占用，不临时编排序权重。
金融知识员联网研究原始论文、银行公开研究和权威常见方法，提供公式、参数依据、可运行工具与样例；该方法研究直接交用户看，不另送审核员。企业应用结果由本企固定审核员审核。

## 从需求推导业务价值
先按[需求到收益证据链](demand-scale-bank-value.md)估计可服务及本行可争取规模，再估计各项收入、资金资本与风险成本。单位交易测算和保本加缓冲只用于解释机制，最终排序须回到企业增量需求及本行可争取的同一年度业务机会。缺内部参数可用行业均值、可比龙头或有依据等比/等差估计，中心值不默认零或全额；估计方法、可比性、调整及区间按需求证据链记录。采用程度进入规模情景，收益与风险假设分别校准，不以同一资金成本前贡献比较所有产品。

## 每项产品必须回答的数字问题
| 视角 | 必须回答 | 口径要求 |
|---|---|---|
| 企业收益 | 预计每年节约或增加多少钱，净收益区间、回收期或其他合适指标 | 对比不新增产品及现有安排，扣收费、改造、实施和持续使用成本；避免把释放的资金本金当利润 |
| 企业风险 | 基准与压力情景可能损失多少，波动如何变化 | 分信用、汇率、流动性、操作等相关风险；风险下降不自动等于确定利润 |
| 企业意愿 | 采用意愿有多强，潜在规模及影响因素是什么 | 结合经济收益、既有工具、切换成本、迫切性；概率须有校准依据，缺依据用意愿分层、可解释情景或临界值，不伪造精确概率 |
| 银行投入 | 平均及峰值资金需求、资金期限、资本占用、实施运营投入 | 贷款余额、衍生品名义本金/实际敞口/保证金、现金管理实施投入分别列示；资金和资本不能混为一个数字 |
| 银行收益 | 收入、扣成本后的净收益区间、合适的收益率和回收期 | 明确分子分母、税前税后、期限及年化；利息/手续费/资金价值去重，扣资金、运营、风险成本等 |
| 银行风险 | 预期损失、压力损失、信用/市场/流动性/操作风险与集中度 | 风险参数须有来源或显式估计方法，不能把企业信用好写成零风险；风险缓释后的剩余风险仍计入 |

跨产品同时展示净收益金额、资金和资本效率，不能只比较百分比。零或很小资金分母的收费业务不得显示无穷收益率；采用可比的资本/投入指标并保留绝对净贡献。对套保，预算波动减少与预期现金收益分开；现金沉淀需估计稳定比例和内部资金价值，不能把全部余额当可用资金或收入。

## 金融知识员的研究与交付
1. 网上查找论文及常见方法。至少比较适用于贷款/保理、现金管理/结算、外汇套保的计算框架；研究风险调整收益、资金与资本成本、情景/敏感性分析、企业收益评估及采用意愿方法。选择哪些公式由研究证据决定，不预定未经核验的公式或门槛。
2. 交付来源表：作者/机构、题名、年份、链接、页码或章节、对应公式/参数及适用范围，优先原始论文和官方方法，避免只引搜索摘要。
3. 交付参数字典：变量、单位、期间、来源、观测/估计/假设标签、区间依据、企业与银行适用性、重复计量检查。
4. 交付可运行计算工具及样例，基准/较好/压力情景与敏感性分析；记录假设、输出和复算步骤。无法支持点估计时给区间或盈亏平衡阈值，仍须提供可用判断。
5. 交付三企7—9月的数据适配表，列可直接取数、可估计及关键待补参数；历史模拟严格按当月公开信息截断。后来的论文可用于方法研究，但后来的企业信息、行情和参数不得泄漏到历史测算。区分当时可用方法与事后研究方法。
6. 交付面向用户的方法说明、计算结果样例和推荐如何产生，直接供用户阅读，不送金融审核员，不称独立审核PASS，不自动发布为已审核知识。相关方法状态记为user_review_pending；用户看过不等于用户已经批准。

## 月报呈现
正文用清楚的数值区间和简洁说明回答“银行投入多少、赚多少、承担什么风险、企业为什么愿意用”，详细公式和参数放附录或配套计算文件。只比较上一报告期经营及推荐变化，不介绍编辑版本区别。不凑前三、不写空泛优势、不堆边界条件。三企执行员代入本企真实值或有依据的估计，不自造参数。现有候选和审核记录保留，方法研究本身不走审核员流程。


缺失参数按[真实数据流程](quant-real-data-rerun.md)处理：停搜后继续估计或替代计算。方法岗应提供能形成判断的区间、单位效率和临界值方法，不能仅返回空值让企业等待。实际数据、估计和演示样例严格分开。
