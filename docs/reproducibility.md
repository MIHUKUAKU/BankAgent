# 复现范围

## 可以直接复现

- 创建空数据库、查看状态、运行模拟演示及查询。
- 候选审核发布、权限隔离、历史保留及跨审边界的自动化测试。
- 安装 Matplotlib 后的绘图测试。

## 需自行提供输入

真实资料导入需要知识包、对应审核记录及来源快照。查看 `python3 -m bankagent --help` 和各子命令 `--help` 获取输入参数。发布包不包含研究工作区的默认导入文件；不要把模拟演示结果当真实企业资料。

文档解析需安装可选解析依赖，并按 `parser-setup --help` 获取固定版本模型。模型和第三方文档不随仓库分发。

## 报告的复现限制

PDF 是研究成果展示，包含来源和估计方法，但本发布范围未包含完整计算脚本、全部参数及历史证据。因此不能宣称只运行本仓库即可逐项重建报告数值。报告中的估算、压力损失和服务范围应与原始披露一同理解。
